# 💊 Frappe Pharmacy Batch, Expiry & FEFO Inventory Tracker

[![Python 3.9+](https://img.shields.io/badge/python-3.9+-blue.svg)](https://www.python.org/downloads/)
[![ERPNext](https://img.shields.io/badge/Frappe-Healthcare-blue.svg)](https://frappeframework.com)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

An enterprise **Pharmaceutical Inventory & Batch Tracking Engine** for **Frappe Framework**. Enforces strict **First-Expiry-First-Out (FEFO)** dispensing algorithms, tracks manufacturing and expiration dates per batch, and generates 90/60/30-day early expiry alerts.

---

## ⚡ Highlights
- 📦 **FEFO Allocation**: Automatically dispenses earliest-expiring batch first.
- ⏰ **Near Expiry Alerts**: Flags medicines approaching shelf-life boundaries to prevent financial write-offs.
- 📜 **Schedule H Compliance**: Prescription verification flag for restricted medicines.
- 🧪 **Pytest Coverage**: Unit tests included.
